Pure CSS Accordion

How does ycsts compare to Tailwind CSS?
ycsts combines comprehensive utility classes with pre-built component classes and signature animations like fadein right out of the box, requiring zero JavaScript build configuration to get started.
Can I use ycsts with React, Vue, or Next.js?
Yes. Since ycsts outputs standard CSS files (ycsts.css and ycsts.min.css), you can import it into any framework with simple standard CSS imports.

Quick Start

Choose the method that best fits your workflow.

1. Instant CLI Initialization

Scaffold a working starter project with local CSS bundle in seconds:

npx @yanzyu/ycsts init

2. Install via npm

Add ycsts as a dependency in your modern Node.js project:

npm install @yanzyu/ycsts

Import into your JavaScript or HTML:

<link rel="stylesheet" href="node_modules/@yanzyu/ycsts/dist/ycsts.min.css">

3. Direct CDN Link

No installation required. Drop directly into any HTML document:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@yanzyu/ycsts@1.1.0/dist/ycsts.min.css">
