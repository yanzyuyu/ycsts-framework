Utility-first CSS.
Fadein in one word.

ycsts is a complete CSS framework covering layout, spacing, color, typography, animation, and interactivity. Add the class fadein to any element and it fades in.

Get started See what's included

What ships with ycsts

Every utility class you need. No configuration required to start.

Layout

Flexbox, grid, container, positioning, overflow, z-index, display utilities for every layout pattern.

Spacing

Margin and padding across all directions with a 36-step scale. m-, mx-, my-, mt-, mr-, mb-, ml-, p-, px-, py- and more.

Colors

Full 22-palette, 11-shade color system. text-, bg-, border-, ring- variants for slate, gray, zinc, red, blue, green and 16 more.

Typography

Font size xs through 9xl, all weights, all families, line-height, letter-spacing, text-align, transforms, decoration.

Effects

Shadow sm through 2xl, ring 1-8, opacity 0-100, blur, brightness, contrast, grayscale, invert, saturate filters.

Animations

Spin, ping, pulse, bounce — and the signature fadein class with fast, slow, and delay variants.

Responsive

sm: md: lg: xl: 2xl: breakpoint prefixes on all utilities. Mobile-first media queries built in.

State variants

hover: focus: active: disabled: checked: placeholder: first: last: odd: even: group-hover: focus-within: and more.

Components

Pre-built btn, card, badge, input, select, alert, avatar, spinner, progress, table, nav, modal, breadcrumb.

Usage

Link the stylesheet and start writing classes.

Install

npm install ycsts

Link in HTML

<link rel="stylesheet" href="node_modules/ycsts/dist/ycsts.css">

Use fadein

<h1 class="fadein">This fades in</h1>
<p class="fadein fadein-delay-1">This fades in after 100ms</p>
<p class="fadein fadein-delay-2">This fades in after 200ms</p>

Fadein variants

fadein 0.4s ease-out
fadein-fast 0.2s ease-out
fadein-slow 0.8s ease-out
fadein-delay-1 100ms delay
fadein-delay-2 200ms delay
fadein-delay-3 300ms delay
fadein-delay-4 500ms delay
